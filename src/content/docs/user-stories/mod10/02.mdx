## Historia de usuario:

**dado** que ya se mostro el formularío del perfilamiento demográfico

**como** usuario/socio de Planet Fitness,

**quiero** seleccionar mi género mediante botones visuales

**para** completar mi perfil de forma rápida y sencilla.

## Criterios de aceptación:

  - Deben existir las opciones:
      - Masculino
      - Femenino
      - Otro
  - Solo una opción puede estar seleccionada.
  - El campo es obligatorio.
  - Debe existir retroalimentación visual de selección activa.
  - No se permite captura manual de texto.
