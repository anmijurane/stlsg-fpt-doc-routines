## Historia de usuario:

**dado** que se aplicarán variaciones de aparacion de formulario

**como** gestor del sistema,

**quiero** preparar el módulo para integrar términos y condiciones posteriormente

**para** habilitar cumplimiento legal futuro sin rediseñar el formulario.

## Criterios de aceptación:

  - El formulario deberá permitir incorporar posteriormente:
      - Checkbox de aceptación.
      - Modal o desplegable de términos.
  - La estructura visual deberá contemplar espacio para esta funcionalidad.
  - La lógica deberá poder habilitar bloqueo del botón “Enviar”.
  - La funcionalidad podrá activarse mediante configuración futura.
